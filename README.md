# 개발자 도구 부수입 엔진

목표: **월 50만원(약 $350)** — 익명으로 만든 개발자 도구를 마켓플레이스에 올려서.

## 사용자가 볼 파일은 하나다

👉 **[`APPROVALS.md`](./APPROVALS.md)** — 승인과 요청이 여기 쌓인다. 비어 있으면 할 일 없음.

## 왜 이 경로인가

제약 조건이 경로를 하나로 좁혔다.

| 조건 | 결과 |
|---|---|
| 가용 자본 500만원 미만 | 자본소득 폐쇄 |
| 가용 시간 주 1~3시간 | 외주·대행·영업 폐쇄 |
| 전부 익명 | 강의·전문가활동·유튜브 폐쇄 |
| **IT·개발·데이터 경력** | ← 남은 유일한 자산 |

그리고 이 조합은 우연히도 **자동 생산자의 약점이 전부 사라지는 자리**다.

| 일반적 약점 | 개발자 도구에서는 |
|---|---|
| 이미지 생성 불가 → 디자인 경쟁 패배 | 기능과 문서가 전부. 아이콘 1개면 된다 |
| 트래픽을 맨바닥에서 만들어야 함 | 마켓플레이스가 검색·랭킹으로 유입을 준다 |
| 익명이 필요한데 대부분 실명 요구 | 개발자 시장은 익명이 표준 |
| 고객 응대에 시간이 듦 | GitHub Issue 비동기 처리 |

## 수익 구조

```
VS Code 마켓플레이스 (무료 등록)   →  발견성·유입
        ↓ 설치
   7일 체험 → 하드 페이월
        ↓ 구매
     Gumroad (라이선스 키)        →  결제·세금
        ↓
확장이 Gumroad API로 키 검증        →  자체 서버 불필요 = 고정비 0원
```

**$350/월 = 구독 $5 × 70명, 또는 $9 × 39명, 또는 일회성 $29 × 12건.**
도구 3개로 각 $100~200을 노린다. 하나에 걸면 실패 시 전멸이다.

## 설계 원칙 (조사 기반, 반드시 지킬 것)

1. **전부 로컬에서 돈다.** 코드를 외부로 보내지 않는다. 2026년 개발자 도구의 최대 셀링포인트가 프라이버시이고, 부수적으로 서버가 없어 운영비도 0원이다.
2. **좁은 직무 × 높은 단가.** "PostgreSQL DBA의 하루 30분을 줄이는 $19.99"가 "범용 생산성 $4.99"를 이긴다.
3. **DB·테스팅 카테고리 우선.** DevOps·AI는 경쟁이 가장 치열하다.
4. **무료 티어 대신 체험 후 페이월.** 전환율·이탈률 모두 낫다.
5. **무료 대체재가 있으면 만들지 않는다.** 하드 필터로 코드에 박아둔다.

## 보장하지 않는 것

만드는 것은 확실히 한다. **사람들이 설치하느냐는 보장할 수 없다.**
인디해커의 50%는 월 $1K를 못 넘고, 많은 유료 확장이 월 $100 미만이다.
가장 약한 고리는 명확하다 — 주 1~3시간 제약상 마케팅을 거의 못 하고,
**마켓플레이스 내장 유통에만 의존**한다.

이탈 지점은 `METRICS.md`에 숫자로 박아뒀다. 지키지 못하면 경로를 접는다.
